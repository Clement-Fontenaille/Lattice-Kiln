# Knowing When to Quit: A Principled Framework for Dynamic Abstention in LLM Reasoning

## Density

**Density: HIGH.** Almost every section carries load: the MDP reformulation, four proved propositions, the reduction of value estimation to a binary-classification probe, and five experimental sections that each answer a distinct question. The padding is confined to the appendix related-work survey (Appendix A, which restates other people's papers) and to some repetition of the "threshold gives practitioners direct control" line. Perhaps two thirds of the load-bearing signal bears on the Subject, because the paper's decision rule is exactly a stopping criterion derived from an estimate of eventual success — but it is evaluated only on single-chain token-level generation, never in a multi-step or tool-using loop.

## Approach

The paper asks when a language model generating a chain of thought should stop and abstain, and it answers by turning the question into an optimal-stopping problem inside a KL-regularized reinforcement-learning objective.

The construction proceeds in four moves.

**1. Generation as a sparse-reward MDP.** A prompt `x` is the initial state, a token prefix `y_{1:t}` is a state, the language model is the policy `π`. The reward is zero at every intermediate token and non-zero only at the `eos` token, where it equals a terminal verifier score `r(x,y)` minus a KL penalty `β·log(π/π_ref)`. The objective `J_β(π)` is the expected total reward under the prompt distribution. Because the reward is sparse and terminal, the state value function `V_β(x, y_{1:t}; π)` is simply the expected terminal reward reachable from the current prefix.

**2. Abstention as an explicit action.** The action space is augmented with a special token `⊥`. Choosing `⊥` halts generation immediately and triggers a fallback — deferral to a human expert, refusal, or routing to a stronger model — and earns a fixed scalar reward `r_⊥ ∈ (0,1]`. Because the reference policy `π_ref` assigns zero probability to `⊥`, the KL term would be undefined for that action, so the authors compute the KL only over non-abstention tokens using an "abstention-stripped" policy `s(π†)`, the next-token distribution conditioned on not abstaining. When a policy never abstains the whole formulation collapses to the standard one, so it is a strict generalization.

**3. The stopping rule.** The objective decomposes as `J_β = α·r_⊥ + (1-α)·S`, where `α` is the abstention rate and `S` is the expected reward among the answers actually delivered. Rewritten as `J_β = S - α(S - r_⊥)`, this makes maximizing `J_β` equivalent to maximizing selective accuracy subject to an abstention penalty, and sweeping `r_⊥` traces out the accuracy-abstention frontier. Since the value is linear in the abstention probability `p` at each state, maximizing over `p` yields a *deterministic* rule: the optimal policy abstains if and only if the expected value of continuing falls below `r_⊥` (their Equation 7). That condition is necessary but circular, because the value function it references belongs to the very policy being modified. The authors break the circle by defining the **dynamic value-thresholding policy** `a(π)`: abstain at a state exactly when `V_β(state; π) < r_⊥` — thresholding the *base* policy's value — and otherwise sample from `π` unchanged. They verify in Appendix B.1 that `a(π)` satisfies the necessary condition.

This is a **myopic, one-step rule with no lookahead**. It compares a scalar at the current prefix against a scalar constant, at every token position. The lookahead is folded into the definition of the value function rather than into the decision procedure — `V` is already an expectation over all continuations, so the rule inherits the horizon without searching it. There is no rollout, no tree, no branching. This is why the per-step cost is negligible.

**4. Estimating the value.** Under `β = 0` and binary rewards `r ∈ {0,1}`, the value function at a non-terminal prefix collapses to `V_0(x, y_{1:t}; π) = P_π(r(x,y) = 1 | x, y_{1:t})` — the probability that this trajectory eventually produces a correct final answer, conditioned on the prefix so far. Terminal states are assigned value 0, since no further reward can be collected. This identity converts value estimation into binary classification, and — crucially — the label is *the same* for every prefix of a completed trajectory, so all positions can be trained in parallel with one binary-cross-entropy loss over prefixes (their Equation 13). Under a realizability assumption, minimizing that loss recovers the true value function (Proposition B.2); Appendix B.8 extends the guarantee to general bounded rewards via MSE.

**What the estimator is, concretely.** It is an **external probe, not the model's own verbalized judgement**: a two-layer MLP on the final-layer hidden state `h_t`. The authors note the causal structure of the transformer guarantees `h_t` depends only on `(x, y_{1:t})`, which is exactly the conditioning set in the target quantity. The probe adds roughly 10^4 parameters against 4B- and 7B-parameter base models, so the per-token cost is one small MLP forward pass — negligible relative to the transformer step it rides on. Training is a one-time offline cost: generate full trajectories with the base model, extract hidden states, fit the probe (reported at roughly 10-40 hours total in Appendix H).

## Theoretical guarantees

All four results assume an **oracle value function**; estimation error is handled empirically in Section 6.4, not theoretically.

- **Lemma 4.1 (value dominance).** At every reachable non-terminal state, `V(a(π)) ≥ max(r_⊥, V(π))`, proved by backward induction. The intuition is that `a(π)` intervenes precisely where intervening helps, swapping low-value continuations for `r_⊥` and leaving high-value trajectories untouched.
- **Proposition 4.2 (dominance over no abstention).** For any base policy and any `β ≥ 0`, `J_β(a(π)) ≥ J_β(π)` and `J_β(a(π)) ≥ r_⊥`, with strict improvement if and only if some reachable non-terminal state has `V < r_⊥`.
- **Proposition 4.4 and Corollaries 4.5, 4.6 (dominance over fixed-position abstention).** Fixed-position abstention `f(π;k)` applies the same value test at one predetermined token position `k` (`k=1` recovers prompt-only "input processing"; `1<k<T` recovers mid-generation methods that check at a fixed offset). The dynamic rule dominates `f(π;k)` up to an **expected recovery surplus** term, which is non-zero only when the dynamic rule quits before `k` on a trajectory that would have recovered above `r_⊥` by position `k-1`. The authors name this honestly as the "option value of waiting" that a delayed decision exploits — this is the paper's own statement of its quit-too-early risk. The surplus vanishes, and dominance holds unconditionally, in two cases: when the dynamic rule never quits before `k` (Corollary 4.5, which covers `k=1` by definition), and when low-value states cannot recover by `k` (Corollary 4.6).
- **Proposition 4.7 (optimality).** With `β = 0` *and* a base policy that is itself optimal over the unaugmented vocabulary, `a(π*)` is optimal among all abstention-augmented policies. The authors flag the reason the base-optimality condition cannot be dropped: abstention can avoid bad outcomes but cannot improve the quality of completed generations.
- **Proposition 4.9 (linear improvement bound).** With `β = 0`, binary rewards, and an `L`-Lipschitz value function (one token moves `V` by at most `L`), the gain is bounded by `α_1·r_⊥ + (α - α_1)·L`, where `α_1` is the immediate-abstention probability. Improvement is therefore at most linear in the abstention rate. For binary rewards `L = 1` holds trivially; the bound only bites when a single token does not decide the outcome, which the authors argue is plausible for chains of thought that self-correct with phrases like "wait" or "let me reconsider".

## Models targeted and benchmarks used

**Models.** Qwen2.5-Math-7B-Instruct and Phi-3-mini-4k-Instruct. Both are small open-weight models. No frontier or reasoning-trained model is tested.

**Datasets.** Two chain-of-thought math benchmarks chosen to bracket difficulty: GSM8K (grade-school word problems, base accuracy 87% for Phi-3 and 88% for Qwen) and OlympiadBench (competition problems, base accuracy 16% for Phi-3 and 43% for Qwen). Plus one non-math generalization test: RealToxicityPrompts, 500 training and 500 test sentence beginnings, with Qwen2.5-Math-7B-Instruct, where the binary reward is non-toxicity rather than correctness and the labels come from querying Claude with a yes/no toxicity template.

**Baselines**, each run at both `t=0` (prompt only) and `t=k` (fixed mid-generation position), with the probe and LoRA head *retrained at position k* for fairness:
- *Constant Step Probe* — the same two-layer MLP architecture evaluated at one fixed position rather than every position. This is the paper's own method held still, and it is the strongest baseline.
- *Self-Assessment* — prompt the model with "Can you correctly answer this question?" and read the yes/no token logits. This is the closest thing to the model judging its own work in the model's own voice.
- *LoRA Abstention* — LoRA-finetune the base model with explicit abstain / do-not-abstain tokens and threshold their logits.
- *No abstention* — the base policy.

`k = 20` for GSM8K, `k = 100` for OlympiadBench. The authors explicitly call both choices arbitrary and devote Appendix K to arguing that the arbitrariness of `k` is itself an argument for going dynamic: at the 60-80% abstention rates they treat as the natural operating regime, the dynamic method quits at a mean of 16-34 tokens (median 9-14) on GSM8K, and that range shifts substantially with `α`, so no single `k` can track it.

## Measurement methodology

**Dependent variables.** Two, kept separate. (1) *Selective accuracy*: mean correctness among non-abstained samples, plotted against abstention rate `α`. This isolates the ranking quality of the value estimate. (2) *Estimated reward* `Ĵ` plotted against a calibrated `r̂_⊥`, which tests the theory's dominance predictions directly. A third, secondary metric appears in Appendix J: *abstention precision*, `P(incorrect | abstained)`, benchmarked against the base error rate that random abstention would achieve. Token savings are reported as a percentage of the savings achieved by the `t=0` constant-step probe.

**What is controlled.** The dynamic method and the strongest baseline share the same probe architecture and differ only in whether the probe is evaluated at every position or one; the fixed-position baselines are retrained at `k`; hyperparameters are matched between the dynamic head and the first-token baseline. An 80/20 train-test split is used throughout. Thresholds are set as the `α`-quantile of estimated values on a held-out set, so every method is compared at matched abstention rate rather than at matched threshold.

**N and variance.** All results are averaged over 5 random seeds (42-46), where a seed corresponds to an independent retraining of the probe; shaded regions in figures are ±1 standard deviation across seeds. The threshold-transfer experiment additionally uses 20 random test-set half-splits per seed. Absolute dataset sizes for the math benchmarks are not stated in the main text; the toxicity experiment states 500/500.

**How significance is treated.** There are no hypothesis tests, no p-values, and no confidence intervals. The argument rests on seed-level standard deviation bands and on the claim of *pointwise* dominance: the authors state that at every abstention rate, on every model-dataset pair, the dynamic curve lies strictly above the best baseline. For the cross-dataset transfer figure the "best baseline" is chosen pointwise per abstention rate, seed, and setting, which is the conservative direction for a comparison.

**One methodological wrinkle worth flagging.** The reward-objective evaluation (Section 6.2, Appendix D) needs `r̂_⊥` on the same scale as true correctness probability, but the method thresholds a possibly-miscalibrated estimate `V̂`. The authors fit isotonic regression from estimated values to empirical correctness, and apply it to the threshold to recover an effective `r̂_⊥`. They calibrate on `V̂_τ`, the value at the moment abstention triggers, arguing that `V̂_τ ≈ T_α` by construction since abstention fires at the first crossing. The isotonic fit is done *separately per threshold level*, which they acknowledge gives no monotonicity guarantee across thresholds, and they exclude points where `r̂_⊥` saturates at exactly 1 as a finite-data artifact of piecewise-constant fitting. This is why the x-axis of Figure 3 does not span [0,1]. The procedure is disclosed carefully, but it is a non-trivial analysis layer sitting between the theory and the plot that supposedly confirms it, and the calibration figure (Figure 6) shows that *both* the baseline's `V̂_0` and the method's `V̂_τ` are miscalibrated across all settings.

## Key findings

**1. Dynamic thresholding beats every baseline on selective accuracy, everywhere tested.** On GSM8K, selective accuracy of 0.92 at 10% abstention rising to 0.99 at 90%, for both models. On OlympiadBench the margins are much larger: with Phi-3 at 90% abstention, 0.64 selective accuracy against 0.34 for the best prompt-only baseline and 0.33 for the best fixed-position baseline, roughly double either. With Qwen at 90% abstention, 0.91 against 0.69 and 0.75. The authors read this as the advantage being most pronounced on harder problems and at higher abstention rates, which is where a wrong answer is most likely and a fallback most valuable.

**2. The two "ask the model" baselines barely work at all.** Self-Assessment (prompting "Can you correctly answer this question?") and LoRA Abstention (finetuned abstain tokens) show, in the authors' words, limited discrimination ability, often performing near or below the no-abstention baseline. More striking: giving them k tokens of partial generation to look at does not substantially help, because the fixed-position variants plateau near no-abstention accuracy regardless of the abstention rate. The signal that works is a probe read off the hidden state; the signal expressed through the model's own output tokens does not.

**3. On the accuracy-versus-cost frontier, the dynamic rule buys accuracy at a modest cost in savings.** Because it waits for the value to drop rather than deciding at t=0, it necessarily saves fewer tokens than prompt-only abstention. It retains 63-86% of the input-only method's token savings at 10% abstention rates, rising to 92-95% at 90% rates. Appendix F is the reason the penalty is small: abstention consistently occurs in the first half of generation, with the mean quit point below 0.5 of trace length even at 10% abstention and below 0.15 at 90%, so most of the would-be trace is still avoided. In the 60-80% abstention regime the mean quit point is 16-34 tokens.

**4. The theory's dominance predictions hold empirically even though both of their assumptions fail.** In Section 6.2 the dynamic curve lies above the diagonal, above no-abstention, and above all baselines at matched calibrated abstention reward. The authors are explicit that neither precondition for Proposition 4.7 holds in their experiments, because the value function is estimated rather than oracle and the base LLMs were trained with KL regularization and approximate optimization. They therefore present this as empirical support for the predictions rather than as confirmation of the theorem. Appendix I shows improvement over no-abstention growing with the abstention rate, which they offer as support for the intuition behind Proposition 4.9.

**5. The threshold is easy to set and it transfers.** Calibrating the threshold on one random half of the test set and measuring the achieved abstention rate on the other, across 5 seeds times 20 splits, gives mean absolute error below 1.2 percentage points in all settings. This is a practical claim about the abstention-rate parameterization, not about the abstention reward as a utility: when the target is a rate, the threshold is just a quantile.

**6. Only the ranking matters, when the threshold is set by target abstention rate.** Because the threshold is a quantile, selective accuracy depends solely on the ordering that the value estimate induces. Appendix G confirms this exactly: applying a square, a square root, or a shifted sigmoid to the estimate produces curves that overlap precisely. Under additive Gaussian noise that does corrupt the ordering, degradation is graceful. GSM8K loses roughly 1-2% at noise equal to one standard deviation of per-sample minimum trajectory values and 7-9% at two standard deviations, while OlympiadBench is more sensitive, which the authors attribute to the harder task leaving less margin in the value function. Gains over no-abstention survive at every noise level tested.

**7. The probe transfers across datasets zero-shot.** Trained on GSM8K and evaluated on OlympiadBench, the probe closely matches in-domain dynamic performance across all abstention rates; the reverse direction shows a slightly larger gap. Both directions still beat every baseline. The authors read this as the probe capturing general hidden-state properties predictive of eventual correctness rather than dataset-specific surface cues. Note the framing: this is transfer of the probe, using the in-domain threshold calibrated on a held-out split of the training dataset.

**8. Abstentions are targeted rather than indiscriminate.** Appendix J's precision metric, the probability that an abstained trace would have been answered incorrectly, exceeds both the base error rate that random abstention would achieve and all baselines, across every setting and abstention rate.

**9. The framework generalizes past correctness to any bounded reward, and this is demonstrated once.** On RealToxicityPrompts, the non-toxic rate among non-abstained samples reaches a perfect 1.00 at only 30% abstention and dominates all baselines pointwise; the strongest baseline there, self-assessment, only matches that from 60% abstention onward.

## On the hard tail: does it quit too early on solvable-but-hard problems?

The brief asks this directly, and the paper's answer is partial, so it is worth stating precisely.

**Where the paper addresses it.** The risk is named exactly once, in the theory, as the expected recovery surplus term in Proposition 4.4. That term is the mass of trajectories the dynamic rule kills before position k which would have climbed back above the threshold. This is the authors' own formalization of premature quitting, and their two corollaries are precisely statements of the conditions under which it is zero: either the rule never quits that early, or low-value states genuinely cannot recover. They do not measure the term. Proposition 4.9's Lipschitz condition is the closest thing to a handle on it, because a value function that can swing by a lot in one token is one where a threshold crossing is a poor signal. The authors' own example of a large swing is self-correction ("wait", "let me reconsider"), which is the exact mechanism by which a hard-but-solvable trace recovers.

**What the evidence suggests indirectly.** The gains are largest on the hard dataset, OlympiadBench, which is the opposite of what one would expect if the rule were systematically discarding solvable-but-hard problems. Appendix J's precision result says that abstained traces really were disproportionately headed for failure. But both of those metrics are aggregates measured at a fixed abstention rate, and neither isolates the subpopulation in question. Selective accuracy is by construction blind to what was thrown away: quitting on a hard problem that would eventually have been solved raises selective accuracy while lowering the total number of problems solved.

**What is not measured.** There is no reported count of correct-answer traces terminated by the rule, no per-difficulty-stratum breakdown, and no comparison against an oracle stopper. Appendix G's noise sensitivity is the honest signal here, because saying that OlympiadBench "leaves less margin in the value function" is the same as saying the hard-tail decision is the fragile one. And the paper's own stated limitation is that a fixed abstention reward is wrong for exactly this case, since a nearly-solved question is worth continuing even at moderate confidence.

## Open questions the paper itself raises

- **Continuous rewards.** All experiments use binary labels, either correctness or non-toxicity, but the propositions hold for any bounded reward. The authors propose substituting a learned preference model's continuous score and training the probe by MSE per Proposition B.3, which would extend the method to tasks graded on a scale.
- **State-dependent abstention reward.** This is their sharpest self-criticism. The framework assumes a fixed fallback utility, "but in deployment, a question the model has nearly solved is worth continuing even at moderate confidence." They propose extending to a state-dependent abstention reward. That is an admission that a constant threshold misprices the work already done.
- **Calibration when the threshold is a real utility.** They separate two deployment regimes. When the threshold targets an abstention rate, only ranking matters and calibration is irrelevant. When the abstention reward is instead specified directly as the utility of the fallback, which is the semantically meaningful use and the one the whole RL framing is built to license, calibration becomes load-bearing, and they say the Appendix D miscalibration analysis "suggests room for improvement in this regime." This is a significant gap between what the theory promises and what the experiments validate.
- **When hidden states do not carry the signal.** They state that the method is limited where hidden states do not encode enough information about eventual correctness, or where optimization fails to extract it, and they assert that these issues are not severe in practice on their settings.
- **Composition with layer-wise early exit.** Appendix A.4 notes that their method exits along the sequence dimension while classical early-exit methods exit along depth, and that the two are complementary and could be combined. This is untested.
- **Over-reliance and disparity.** The impact statement raises that a well-functioning abstention mechanism may induce users to assume the model always abstains when uncertain, and that abstention rates varying systematically across problem types or user populations would create disparities in service quality.

## Appreciation

### Mechanism

The mechanism is elegant, and I take it to be the durable contribution independently of any number in the paper.

The central move is recognizing that sparse terminal reward collapses the value function into a single quantity that is the same target at every prefix. Once the value equals the probability of eventual correctness given the prefix, three things follow at once that would otherwise each be hard. Value estimation becomes binary classification with a proper loss. Every prefix of a completed trajectory becomes a training example carrying that trajectory's own final label, so training runs in parallel over positions and requires no per-step credit assignment. And the stopping rule becomes a comparison of two scalars, so the decision is myopic in implementation while remaining forward-looking in content, because the horizon lives inside the value function rather than inside a search.

The second good move is giving the threshold a semantics. The abstention reward is not a tuning knob dressed up as a quantity; it is the utility of whatever the fallback is, whether that is the human reviewer, the stronger model, or the refusal. That makes the stopping rule an economic comparison, asking whether continuing is worth more than handing this off, rather than a heuristic confidence cutoff. It also explains why the same rule is correct at any operating point: you do not retune the rule, you restate what your fallback is worth.

The third is the target choice, which is argued against the obvious alternative. The authors take direct aim at Zhang et al. (2025), who probe intermediate answer correctness at reasoning-chunk boundaries. Their objection is sharp and I think correct: a correct intermediate answer can later be revised into a wrong one and vice versa, so intermediate correctness is the wrong thing to threshold. What matters is whether the final answer will be right, and that is precisely what the value function is. This distinction, between "am I right now" and "will this attempt end up right", is the paper's most transferable idea.

The fourth is the invariance argument. Recognizing that quantile-based thresholding makes the whole method depend only on the ranking the estimate induces, and then demonstrating exact invariance under monotone reparametrization, converts what looks like the method's most fragile dependency, a calibrated probability, into a much weaker requirement, an ordering. That is a real robustness result, and it is honest about its own boundary, because the invariance evaporates in the regime where the threshold is a stated utility.

I also credit the framing of the arbitrariness of k as evidence. Rather than tuning k to a favorable value, the authors document that the dynamic method's own quit point moves by a factor of several across operating points, and they conclude that no fixed k can track it. Turning the baseline's hyperparameter problem into a structural argument is a better use of that appendix than a tuned number would have been.

### Magnitude

The magnitudes are large, but the conditions under which they were obtained shrink them considerably.

The jump from 0.34 to 0.64 selective accuracy on Phi-3 with OlympiadBench is the headline, and it is a big effect. Three things temper it. First, it is measured at 90% abstention, which means the system answers one problem in ten. At that operating point, on a task where the base model is right 16% of the time, "64% selective accuracy" describes an extremely small delivered set, and the comparison against baselines is a comparison among ways of picking a tenth of the problems. Second, the strongest baseline is the same probe held still, so a large part of what the headline measures is the value of evaluating at every position rather than at one. That is genuinely the paper's claim, but it is a narrower claim than "beats abstention methods in general". Against the two methods that ask the model itself the margin is enormous, but those methods barely clear no-abstention, so the bar there is low. Third, the GSM8K numbers, where base accuracy is already 87-88%, leave much less room: 0.92 at 10% abstention is a modest improvement over a strong base rate, and the paper itself calls GSM8K the setting with its smallest gains.

The cost side is honestly reported and modest in the good direction. Retaining 63-86% of prompt-only token savings at low abstention rates is a real price paid for the accuracy rather than a free lunch, and the authors say so plainly. The overhead claim, roughly 10^4 probe parameters against 4B and 7B base models and one small MLP pass per token, is credible on its face and is the least contestable magnitude in the paper.

The theory's magnitudes are weak by design, and the authors say so. Proposition 4.9 bounds improvement from above, linearly in the abstention rate, and with binary rewards the Lipschitz constant holds trivially at 1, which makes the bound vacuous unless one can argue for a tighter constant. The authors argue for a tighter one informally; they do not measure it. So the theory establishes direction, meaning dominance, robustly, and it establishes size not at all.

Variance handling is adequate but thin: 5 seeds, bands of plus or minus one standard deviation, and no inferential statistics. For a paper whose central empirical claim is pointwise dominance at every abstention rate in every setting, seed bands are the right visualization, and the claim is bold enough that a single crossing would falsify it. Even so, "strictly dominates pointwise" asserted from 5 seeds of probe retraining is a stronger statement than the statistics presented can license.

### One internal inconsistency

Appendix H does not match the rest of the paper. It reports evaluating "Phi-3-small-8k-instruct and Mistral-7B-Instruct-v0.3" across "OlympiadMath, OlympiadPhysics, GSM8K", and it states that "all methods used abstention thresholds of [0.3, 0.5, 0.7]", whereas the main text tests Phi-3-mini-4k and Qwen2.5-Math-7B on GSM8K and OlympiadBench and sets thresholds as quantiles rather than at three fixed values. It also glosses "RTP" as "Reason-Then-Predict", while RTP elsewhere in the paper refers to RealToxicityPrompts. This reads like a stale setup appendix carried across revisions, and it is the one place where the paper's bookkeeping does not inspire confidence. It does not touch the theory, but it does mean the reproducibility appendix cannot be taken at face value, and the released code would have to settle it.

## How it could serve a harness-design effort

Read against the Subject, which is an agent loop deciding whether its current attempt has succeeded, stalled, or should be handed off, this paper is best treated as a rigorous account of a smaller-scale version of the problem, whose conceptual apparatus transfers better than its method does.

**What transfers directly.**

1. The right thing to estimate is the probability that this attempt eventually succeeds given the trajectory so far, not whether the current state looks good. The paper's argument against intermediate-answer probing is exactly the argument against a harness that gates on whether the last step looked right. A step that looks wrong may be recovered, and a step that looks right may be discarded later. The quantity that licenses abandoning an attempt is a forecast about the attempt's end, not an assessment of its present.
2. A stopping threshold should be denominated in the utility of the fallback. This is the most directly portable design principle. A harness that hands off to a human, escalates to a stronger model, or restarts with a different plan has a known alternative value, so the stopping question becomes whether the expected value of continuing has fallen below what the handoff is worth. Framed that way, one threshold serves all difficulty levels without retuning, because harder tasks lower the estimated value rather than requiring a different rule. The same knob simultaneously controls escalation rate and cost, which is what an operator actually wants to set.
3. The objective decomposition, which is escalation rate times handoff value plus delivery rate times delivered quality. This is a clean way to state a harness's operating point. It makes explicit that maximizing delivered quality alone is not the goal, and it turns the accuracy-versus-escalation frontier into a single-parameter sweep.
4. Ranking may be enough. If a harness sets its escalation threshold as a quantile against observed traffic rather than as an absolute utility, then only the ordering of its confidence signal needs to be right. That is a much cheaper thing to build and to validate than a calibrated probability, and the paper proves the invariance exactly.
5. A cheap external probe outperformed asking the model. Finding 2 is the most operationally consequential result here for anyone building a self-assessment step into a loop. The prompted self-assessment and the finetuned abstain token both performed near or below no-abstention, and showing them partial work did not help. If that generalizes, then a harness that asks the model "are you making progress?" is reading the weakest available signal.

**Limitations that bound the transfer.**

1. Nothing here is evaluated in a multi-step or tool-using loop. The unit of decision is a token position within one chain of thought, and the unit of abandonment is one generation. There is no environment, no tool call, no observation, no state change, no multi-attempt structure, and no budget spanning attempts. Every reported number is single-chain. The paper acknowledges the adjacent setting only in a single Appendix A.1 sentence, citing Bonagiri et al. (2025) on prompting tool-augmented agents to quit when uncertain, and it explicitly frames its own contribution as complementary and "within-generation". A harness designer should treat the framework as an analogy to be re-derived at step granularity, not as a result to be applied.
2. The MDP assumptions do not survive the translation cleanly. The sparse terminal reward structure is what collapses the value function into a single classification target, and that collapse is the engine of the whole method. An agent loop has intermediate observations that genuinely change state, tool results carrying information the model did not generate, and often a shaped or partial notion of progress. The "same label for every prefix" trick therefore has no obvious analogue, and value estimation reverts to the harder credit-assignment problem that the paper managed to avoid.
3. The probe needs the model's hidden states. The estimator is an MLP on final-layer activations at every position. Those are unavailable through an inference API, and they are also the reason the method is cheap. A harness working behind an API cannot implement this mechanism, only its shape, and the paper's own evidence says the API-accessible substitutes, meaning prompted self-assessment and logit-based abstain tokens, are the ones that failed.
4. The probe is trained per base policy on that policy's own trajectories. The value function is defined relative to the policy. Change the model, the prompt scaffold, the sampling temperature, or the tool set, and the object being estimated changes. Cross-dataset transfer was demonstrated, but cross-policy transfer was not tested at all, and it is the transfer that a harness sitting in front of a rotating set of models actually needs.
5. The stated-utility regime, which is the one a harness would actually use, is the untested one. The authors are candid that when the abstention reward is a genuine fallback utility rather than a quantile target, calibration matters, and their calibration is imperfect, since Figure 6 shows both their method and the baseline miscalibrated in all settings. A harness that wants to say "escalate when continuing is worth less than the reviewer's time" is asking for exactly the regime the paper flags as needing improvement.
6. The hard-tail question is unresolved, as set out above. Selective accuracy rewards discarding hard-but-solvable work. For an agent harness the cost structure is often the opposite, because a task abandoned is a task not done and the handoff is expensive, so the metric that made the paper's case is not the metric a harness should adopt.
7. The fixed-threshold limitation matters more in a loop than in a chain. The authors' own future-work note, that a nearly-solved problem deserves continuation even at moderate confidence, is the near-completion problem, and it is far more acute after twenty tool calls than after two hundred tokens. Their proposed fix, a state-dependent abstention reward, is unimplemented.

**Major concerns, ranked.** First, the scale mismatch: single-chain token-level abstention is a different problem from loop-level abandonment, and the paper's strongest guarantees are the ones most dependent on the MDP structure that the translation breaks. Second, the hidden-state requirement rules the mechanism out for API-mediated harnesses while the paper's own results discredit the API-accessible alternatives, which is an uncomfortable pair of findings to hold together. Third, the theory-to-experiment gap: the oracle-value and base-optimality assumptions both fail in the experiments, the improvement bound is vacuous at a Lipschitz constant of 1, and the figure that validates the reward-objective theory rests on a per-threshold isotonic recalibration with acknowledged non-monotonicity across thresholds and with excluded boundary points. Fourth, the evaluation breadth: two small open-weight models, two math datasets plus one toxicity task, no reasoning-trained or frontier model, 5 seeds, and no inferential statistics. Fifth, the Appendix H inconsistency, which is small but is a reproducibility red flag.

## Five citations worth chasing next

1. **Bonagiri, Kumaraguru, Nguyen, and Plaut (2025), "Check yourself before you wreck yourself: selectively quitting improves LLM agent safety," arXiv:2510.16492.** This is the single most relevant citation in the paper for the Subject, and the only one operating in a multi-turn tool-augmented agent setting. It is cited once, in Appendix A.1, for the finding that prompting agents to quit when uncertain substantially improves safety at minimal helpfulness cost. This is the loop-level version of the paper's question, and the paper declines to engage with it beyond that one sentence.

2. **Zhang et al. (2025), the reasoning-chunk early-exit work.** This is the paper's closest empirical competitor and the target of its sharpest methodological argument, namely that intermediate answer correctness is the wrong thing to threshold because it can be revised in either direction. It is reported to cut inference tokens by 24% without accuracy loss. It is worth reading in order to judge whether the value-function target really beats the intermediate-correctness target, because the comparison here is argued rather than run head-to-head.

3. **Manvi et al. (2024), generative self-evaluation for adaptive sample pruning.** This is cited in both A.3 and A.7 as closely related work: the model predicts mid-generation the probability that restarting would yield a better response, using only a single generated token and no external reward model, which enables pruning 50-75% of samples early. This is a restart-or-continue decision rather than an abstain decision, which is nearer to what an agent loop faces, and it requires no hidden-state access.

4. **Qian et al. (2025), on mutual information during generation at "thinking tokens".** The paper leans on this in A.7 for the theoretical explanation of why dynamic monitoring beats fixed-position checking: mutual information between hidden states and the correct answer peaks non-monotonically at reflection tokens such as "Wait" and "Therefore", together with a proof that higher cumulative mutual information tightens prediction-error bounds. This is the mechanism behind the paper's central empirical advantage, and it bears on where in a trajectory a progress signal is worth reading at all.

5. **Afzal, Matthes, Chechik, and Ziser (2025), "Knowing Before Saying: LLM Representations Encode Information About Chain-of-Thought Success Before Completion" (ACL 2025).** This is the strongest counterweight inside the paper's own related work: probes predict chain-of-thought success at 60-76% accuracy before any token is generated, and later reasoning steps do not always improve the prediction. The paper reinterprets that second finding as trace heterogeneity rather than as irrelevance of mid-generation signal, and that reinterpretation is worth checking against the source, because it bears directly on whether continuous monitoring earns its keep over a single up-front assessment.
